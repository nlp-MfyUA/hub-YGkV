# 课程案例与提交项目的对应关系

参考课堂提供的《案例-多模态内容理解.ipynb》中的楼道消防风险识别问题，以及 Qwen2.5-VL 图文问答实现方式。

| 课堂案例 | 本项目改造 |
|---|---|
| 在 Notebook 内输入本地图片路径 | 在网页上传图片或通过手机摄像头拍摄 |
| Qwen2.5-VL 本地加载、图文问答 | DeepSeek V4.1 Flash 或 Qwen3-VL-Flash 的在线 API |
| 通过提示词输出风险类别 | 先输出可见事实的 JSON，再由 Python 执行五级风险规则 |
| Notebook 展示结果 | HTML/CSS/JavaScript 网页展示等级、依据与建议 |
| 单机运行的实验代码 | FastAPI 前后端项目，支持局域网手机访问 |

**保留的作业任务：**非楼道、高风险、中等风险、低风险、无隐患这五类；危险因素包括电动车、电瓶、飞线充电、大量堵塞、大量可燃物与少量堆物。

**改造原因：**将视觉观察和风险规则解耦，便于独立测试、定位问题、维护判定标准；使用在线 API，避免本地运行 7B 级视觉模型所需的 GPU 环境。

**注意：**从 Notebook 中学习了思路和问题定义，本提交文件夹不包含老师原始 Notebook，也不包含照片数据集。没有使用课堂案例生成的真实模型精度指标。
