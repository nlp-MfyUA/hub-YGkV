# 测试与验收说明

## 自动化测试

在项目根目录执行：

```powershell
python -m pytest -q
```

自动化检查范围：
- 6 个布尔字段的所有风险组合（验证非楼道优先、最高风险优先）
- 无效的 JSON、缺失字段、错误类型的响应
- JPEG/PNG/WebP 图片转码和 RGBA 透明图
- 空图、伪造图片、GIF 和超大图片输入
- API 状态接口不会泄露密钥
- 模拟 DeepSeek 与 Qwen 的 API 请求格式、Base64 图片内容和返回 JSON

自动化测试使用 `httpx.MockTransport`，即**不访问实际模型**。

## 人工验收（接入真实 API Key 后执行）

| 测试照片 | 预期类别 | 重点观察 |
|---|---|---|
| 住宅楼道内有电动车或明显飞线充电 | 高风险 | 能否识别危险源 |
| 楼道大量纸箱/木家具或严重堵塞 | 中等风险 | 能否判断数量、是否堵塞 |
| 墙边少量鞋盒/杂物且通行基本正常 | 低风险 | 能否区分少量与大量 |
| 干净无遮挡的住宅楼道 | 无隐患 | 是否误报堆物 |
| 室外风景、宠物、食物等 | 非楼道 | 能否排除无关场景 |

注意：以上是**计划执行的人工场景测试**，没有被伪装为已经获得的真实模型测试结果。
请在自己的电脑上使用不含敏感信息的照片测试，记录预测是否准确，再据此调整 Prompt。

## 结果示例说明

`界面示意报告.png` 是静态示意数据展示的页面截图，**不是 AI 对真实照片的检测结果**。

## 安全和隐私

单图最大 8 MB；后端检查文件真实格式与像素数量，不将照片主动持久化。
图片会经网络提交给所选模型服务商。仅建议在可信网络中进行课程演示。
