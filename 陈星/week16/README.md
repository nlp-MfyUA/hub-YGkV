# ESG 两项作业提交包

本包按作业要求分为两部分。报告为可编辑 DOCX，来源明细与对比结果附 CSV，技能附完整源码目录。

## 作业1：两个 ESG 案例

- 案例一：以中国神华为例的月度 ESG 报告，涵盖政策与标准动态、行业动态及实践、公司影响、同业参照和建议。
- 案例二：ESG、可持续发展及双碳相关中标信息汇总，含招标热点、金额分布和逐条证据表。
- `技能源码/` 下包含两个可复用技能。技能内 `SKILL.md` 是入口，`scripts/` 是确定性脚本，`references/` 是研究和实现说明。

## 作业2：确定性脚本效果对比

- 对比报告和逐条 CSV 展示了同一冻结来源集合在无脚本流程与有脚本流程中的判定差异。
- `复现材料/` 包含输入语料、脚本、基线记录、输出及核对程序，便于复核这次对比。
- 这是对固定来源语料的筛选、分类、金额抽取与汇总对比；互联网搜索发现能力单独记录，不能把固定语料结果解读为端到端召回率结论。
- `chatgpt_search.js` 展示在 ChatGPT 环境中调用联网搜索并结构化候选来源的编排方式；互联网检索依赖运行环境的搜索工具。`esg_pipeline.py` 对已取得的材料做可重复的字段校验、来源去重、证据卡片整理和金额汇总。

## 文件导航

- `作业1_ESG案例交付/报告与数据/`：两个案例报告及中标证据明细。
- `作业1_ESG案例交付/技能源码/`：两个技能的完整可复用目录。
- `作业2_确定性脚本效果对比/`：对比报告、逐来源结果及复现材料。
