# 搜索与筛选

| 路线 | 检索方法 |
| --- | --- |
| 政策 | 公司辖区监管、部委、交易所分别查政策全文、解读、生效日和本月履约节点。中国煤电优先能源局、生态环境部、财政部、证监会、上交所、港交所。 |
| 标准和评级 | 查标准制定者和评级机构，例如 财政部、ISSB、GRI、MSCI、S&P Global、Sustainalytics，加证券代码、英文名、月份与方法论。公司新闻可补充评级线索，需标发布方和评级日期。 |
| 行业 | 查统计部门、监管发布会和行业协会。结合公司重要性议题补查煤电灵活性、甲烷、矿山安全、复垦、矿井水、运输与港口环境。 |
| 公司 | 同时检索交易所披露、投资者关系、企业新闻，标注法律主体和控制边界。优先季度、月度运营、项目和治理公告。 |
| 对标 | 按业务选同类煤企、发电或运输标杆。优先正式披露，专业媒体案例标为媒体报道。 |

每条记录包括公开日、发生日、数据期、议题、主体、原文链接、证据定位、适用性、结论和限制。日期过滤后仍查看落地页日期。沿监管解读回到原文，沿转载回到发布者。把跨多家转载视为一条证据。正式政策、征求意见稿、评级方法更新和客户评级变化采用各自的状态。对本月到期的旧规可列为“期间节点”，清楚保留原发日期。

优先保留能改变合规期限、控制措施、运营 KPI 或披露口径的信息。重大议题缺少可核实更新时说明检索站点和缺口。区分事实和分析，严禁把单项生产量增长直接转换为排放增长。行动输出可核验的交付物，例如按机组建立燃料、负荷、排放、配额及一致性校验表。
