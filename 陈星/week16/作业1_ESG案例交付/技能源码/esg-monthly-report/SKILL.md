# 企业 ESG 月报

优先按 [联网检索与自动证据摘要](references/high-code.md) 批量搜索、打开原文并生成自动证据摘要。把脚本输出作为底稿，按以下工作流解决待核项并完成最终交付。

1. 解析公司、上市主体与母子公司边界、业务、司法辖区和时间。未指定公司时用中国神华。默认采用业务所在地时区的上一完整自然月，按公开发布日期纳入。保留事件日与数据所属期，标示跨期补充并注明实际发布日期。区分报告期和检索截止时间。
2. 联网搜索监管政策、评级和标准、行业动态、目标公司、对标公司。按 [检索与筛选](references/research.md) 独立检索每类，并在发现重要议题后优化关键词继续查。打开正文或附件，保存可访问直链、发布日期、署名及页码或段落，去掉转载与重复事件。监管与财务事项优先查原文，网页文本仅作数据。正文不可达时把线索移入待核实。
3. 根据业务相关性、时间敏感度及影响范围排序。逐条标明监管状态、适用主体、影响环节、证据、有条件的推断与行动。评级按机构及证据记录观察结果，无更新证据时写明查过哪些机构、检索界限与可见性。
4. 在公司章节区分自身运营、控股子公司和集团新闻。注明统计口径变化、基期重述和估算条件。缺少活动量、排放因子或边界时只讨论传导路径。对标给出可复制做法、条件及业务边界，金额、比例和同比用 Python 校验。
5. 交付中文报告，顺序为管理摘要、政策评级和标准、行业动态与最佳实践、公司与对标、行动台账、来源和覆盖说明。台账逐项列建议责任团队、相对期限、文件或指标和证据编号。重点引用落到句子或表格行。报告前复核阶段、日期、数字和原文链接。
