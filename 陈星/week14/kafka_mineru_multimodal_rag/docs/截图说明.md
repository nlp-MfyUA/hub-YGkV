## 跨环境调用 MinerU

MinerU 4.2.1 装在 WSL 的 venv 里（`/home/star/mineru/.venv`），命令行里的定位符读取等功能都在
WSL 侧完成。`app.py` 的 `MINERU_CMD_TEMPLATE` 可以拼出任意调用方式，本机用的是：

```
MINERU_BIN=wsl.exe
MINERU_CMD_TEMPLATE=["{mineru}", "-d", "Ubuntu-26.04", "--", "/home/star/mineru/.venv/bin/mineru", "{subflags}", "{src}", "{outflags}", "{pagesflags}", "{tierflags}", "--wait", "{waittime}"]
MINERU_TIER=basic
MINERU_CLI=/home/star/mineru/.venv/bin/mineru
MINERU_WSL_DISTRO=Ubuntu-26.04
```

如果 MinerU 和 API 在同一个 Linux 环境里，只要 `MINERU_BIN=/path/to/mineru`、`MINERU_TIER=basic`，
不用模板也可以。
