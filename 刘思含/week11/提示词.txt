## 你的任务
按以下五步顺序执行。每步结束输出"步骤 N 完成 + 关键结论"，遇到"停止条件"立即停下，不要自行修复。

## 步骤 1 · 用 conda 创建 Python 环境

执行：

```bash
conda create -n chatbi-vuln python=3.11 -y
conda activate chatbi-vuln
python --version
which python
```

**期望**：`python --version` 输出 `Python 3.11.x`，`which python` 路径包含 `envs/chatbi-vuln`。

**停止条件**：
- conda 不可用 → 停下报告，不要尝试用 venv 替代（用户明确要求 conda）。
- `python=3.11` 安装失败 → 停下报告错误，不要自行降级到 3.10 或 3.9。

**输出**：一句话汇报环境路径与 Python 版本。

---

## 步骤 2 · conda 环境内的 SQLite 与 FTS5 检测

conda 环境的 SQLite 可能与系统 SQLite 不同（conda 有独立的 `sqlite` 包），必须单独检查：

```bash
python -c "import sqlite3; print('sqlite3:', sqlite3.sqlite_version); print('fts5:', sqlite3.connect(':memory:').execute(\"SELECT sqlite_compileoption_used('ENABLE_FTS5')\").fetchone())"
```

**期望**：`sqlite3` ≥ 3.34，`fts5` 输出 `(1,)`。

**若 sqlite3 < 3.34**：
```bash
conda install -n chatbi-vuln -c conda-forge sqlite=3.45 -y
python -c "import sqlite3; print(sqlite3.sqlite_version)"
```
重新检查直到 ≥ 3.34。若 conda-forge 也无法满足，**停下报告**，不要降级到 `unicode61` 分词器（那是 `docs/09_fallback_plan.md` 的 F-04，需要用户决策）。

**输出**：sqlite3 版本与 FTS5 状态。

## 步骤 3 · 本机环境预检测，产出 `docs/environment_report.md`

执行检测脚本（不要用 `pip freeze`）：

```bash
python - <<'PY'
import sys, sqlite3, platform, shutil, subprocess, json
info = {}
info["python"] = {"version": sys.version.split()[0], "executable": sys.executable}
info["sqlite3_builtin"] = {
    "version": sqlite3.sqlite_version,
    "fts5": bool(sqlite3.connect(":memory:").execute("SELECT sqlite_compileoption_used('ENABLE_FTS5')").fetchone()[0]),
}
info["os"] = {"system": platform.system(), "release": platform.release(), "machine": platform.machine()}
info["cpu_count"] = __import__("os").cpu_count()
try:
    with open("/proc/meminfo") as f:
        info["mem_total_gb"] = round(int([l for l in f if l.startswith("MemTotal")][0].split()[1]) / 1024 / 1024, 1)
except Exception:
    info["mem_total_gb"] = None
info["disk_free_gb"] = round(shutil.disk_usage(".").free / 1024**3, 1)
info["gpu"] = None
try:
    out = subprocess.check_output(["nvidia-smi", "--query-gpu=name,driver_version", "--format=csv,noheader"], text=True).strip()
    info["gpu"] = out
except Exception:
    pass
# 项目相关全局包版本（仅三项）
relevant = {}
for pkg in ["numpy", "openai", "paddleocr"]:
    try:
        relevant[pkg] = subprocess.check_output([sys.executable, "-m", "pip", "show", pkg], text=True).split("Version: ")[1].split("\n")[0]
    except Exception:
        relevant[pkg] = None
info["relevant_global_packages"] = relevant
print(json.dumps(info, indent=2, ensure_ascii=False))
PY
```

把输出整理为 `docs/environment_report.md`，格式：

```markdown
## 本机环境检测 · {日期}
- Python: {version}（路径：{executable}）
- sqlite3（Python 内置）: {version}，FTS5: {启用/未启用}
- 操作系统: {system} {release} / {machine}
- CPU 核数: {cpu_count}
- 内存: {mem_total_gb} GB
- 磁盘可用: {disk_free_gb} GB
- GPU: {gpu 或 "无"}
- 项目相关全局包版本（仅供对照，不代表将使用）:
  - numpy: {版本或 null}
  - openai: {版本或 null}
  - paddleocr: {版本或 null}
```

**重要**：`environment_report.md` 只记录**系统级前置条件与全局包现状**，不记录完整的 `pip freeze`。它是"现状快照"，不是"依赖清单"。

**输出**：`docs/environment_report.md` 已写入，一句话汇报关键结论（Python 版本、SQLite 版本、有无 GPU）。

## 步骤 5 · 安装依赖并验证

```bash
conda activate chatbi-vuln
pip install -r requirements.txt
```

安装过程中**不要**修改 `requirements.txt`。若报冲突：

- 若是 `numpy` 相关冲突 → 按 `docs/06_pitfalls.md` P-DEP-002 处理（锁定 `numpy==1.26.4`，先 `pip uninstall numpy -y` 再装）；
- 若是 `openai` / `openai-agents` 冲突 → 按 `docs/06_pitfalls.md` P-DEP-003，**停下报告**，附上 `pip show openai-agents` 的 `Requires` 输出，让用户确认兼容版本，不要自行猜测；
- 其他冲突 → 停下报告完整报错，不要自行降级或跳过。

安装完成后逐条验证：

```bash
python -c "import sqlite3; print(sqlite3.sqlite_version)"
python -c "import pdfplumber; print(pdfplumber.__version__)"
python -c "from agents import Agent; print('agents ok')"
python -c "from paddleocr import PaddleOCR; print('paddleocr ok')"   # 若用 PaddleOCR
```

**若 PaddleOCR 导入报 `libgomp.so.1` 缺失**（`docs/06_pitfalls.md` P-DEP 相关）：这是系统库问题，用 `conda install -c conda-forge libgomp -y` 解决；若仍失败，停下报告。

**输出**：逐条验证结果；若有失败项，附完整报错。

## 硬性约束（再次强调）

1. **不得修改 `requirements.txt`**。它的内容是 `docs/10_environment.md` §2.1 的锁定版本，是"目标状态"，不是"本机状态"。
2. **不得用 `pip freeze` 覆盖 `requirements.txt`**。`pip freeze` 会导出全部传递依赖，破坏锁定清单。
3. **不得用 venv 替代 conda**。用户明确要求 conda 环境 `chatbi-vuln`。
4. **遇到版本冲突先停下报告**，不要自行降级、不要自行升级、不要自行替换库。
5. **`environment_report.md` 记录的是现状，`requirements.txt` 记录的是目标**。两者不一致是正常的，不一致本身不需要"修复"。
