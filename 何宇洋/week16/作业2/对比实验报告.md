# 确定性脚本与纯提示词skill效果对比

## 一、条件与复现

- 模型：gpt-6-astra，来自CLI自身实时`codex debug models`返回的可用目录；CLI版本0.154.0，两组推理强度均low。
- A组：无脚本版skill+冻结原始输入，模型直接推理，不使用工具或计算脚本。
- B组：脚本辅助版skill+相同原始输入+对应脚本真实输出；脚本在模型调用前执行，日志含命令、耗时、退出码。
- 中标输入：11条人工构造记录，不是市场事实。月报输入：作业1的8项真实检索证据台账，冻结核验层级和日期。
- 每个条件1次，4个条件按固定随机种子打乱顺序。样本很小，没有统计显著性或长期稳定性结论。各skill长短及B组附加预处理结果构成真实工作流差异，并非仅替换一个提示词的严格单变量实验。
- 每次使用隔离workspace，期望答案不进入workspace或stdin。输入哈希、完整提示、模型输出、CLI事件、stderr和usage保留在对应目录。

命令（在工作区根目录）：

```powershell
python '作业2/scripts/run_skill_ab_eval.py' --model gpt-6-astra --repeats 1 --timeout 180 --inline
python '作业2/scripts/summarize_cli_ab.py'
python '作业2/scripts/run_comparison.py'
python '作业2/scripts/write_eval_report.py'
```

命令沿用CLI自身认证；本次独立provider仅将传输设为HTTPS，指向同一官方ChatGPT服务，不修改全局配置、认证或读取令牌。模型可用性随账号变化，复现前用`inspect_cli_models.py`经CLI查询目录。

token为CLI `turn.completed.usage`实测，缓存token是输入的子集。CLI耗时包含进程启动、网络和生成，B组另有很短的预处理时间，详见每次`preprocess_execution.json`，表中未计入。中标A组没有缓存而B组有缓存，耗时差异不能单独归因于脚本。没有采用价格表估算费用。

中标评分检查：记录数、有金额数、未知金额数、总额、中位数、最小值、最大值、四档分布字典（算1项）。人工预期为5/3/2条、总额270万元、中位数100万元、最小50万元、最大120万元，分布0/1/2/0。未知金额和费率保留记录但不进金额统计；预算、窗口外、未核验和非实质相关记录剔除；项目总额不叠加标包。

月报评分检查4个证据ID集合：当月M01/M04，背景M02/M07，期后M03，待核验M05/M06/M08。评分只覆盖这一日期与证据分层，不能等同于报告整体质量或事实准确率。

## 三、报告审阅与脚本验证

CLI生成的两篇简报已导出到“评估/报告样例”。人工查看发现两组均覆盖政策标准/评级、行业、公司E/S/G、同业与建议，并区分草案、未经审计报表、背景和期后资料；均明确评级与同业证据不足，未把未核验交易金额写成确认值。此为本次执行者的核查，非独立盲评，不给主观综合分。

脚本共有8组行为测试通过：金额与未知值、黄金统计、更正替代、同日冲突、闰日边界、月报分层、待发送/重复/到期状态、搜索无关结果筛除。固定输入8项汇总字段一致。结构检查4个skill通过；官方quick_validate因本机缺PyYAML未运行成功，保留失败记录，不宣称官方验证通过。

真实案例回放：严格中标1条1699980元；含待核验官方索引8条55989880元，分开呈现；日报只产生本地待发送箱，未向外发送。CLI实验不会改变作业1原始事实的核验层级。

## 四、可以支持的结论与限制

本次小样本中两组结果一致，脚本没有显示准确率优势。脚本的实际价值是让金额、日期、冲突和发送状态的处理可复验、可审计；确定性执行仍可能稳定执行错误规则，需保留测试与原始证据。

端到端在线召回、真实自动工具调用、独立报告质量盲评、重复运行稳定性与成本优势均未在本实验得到证明。没有将单次耗时或规则级满分外推为真实互联网报告的整体效果。
