## 2. 验收证据

### 2.1 多 PDF 上传

`POST /api/documents/upload` 返回：

- doc 3：`vdi-guide.pdf`，859,469 B，最终 `completed`，15 chunks / 8 images
- doc 4（测试重传时可能顺延为 doc 5）：`tax-mindmap.pdf`，49,424 B，最终 `completed`，1 chunk / 1 image

### 2.2 SSE 状态

一次上传期间捕获 4 个 `event: documents`，状态序列：

```text
pending → parsing → completed
```

### 2.3 图文混排问答

问题：`VDI 使用指引中，如何连接和登录？请结合文档中的截图说明。`

回答包含：

- 连接前准备、安装 VMware Horizon Client、添加服务器、桌面使用要点等章节；
- 5–7 张 `/api/documents/3/images/...` 原图（不同轮次模型选图数量不同）；
- 6 条 references（doc 3 的 chunk 0/12/11/14/9/8）。

### 2.4 用户图问

问题：`这张图片是什么颜色？` + 64×64 红色 PNG。

回答：`红色`（并说明为纯红色块）。

### 2.5 图片资源

`GET /api/documents/3/images/page_0_image_0.jpg` → HTTP 200，`image/jpeg`。

### 2.6 会话记录与标题

- 左侧栏展示会话列表（标题 + 日期）；点击某条会话，`ChatView` 调 `GET /api/chat/sessions/{id}/messages` 恢复消息。
- 新建会话提问后，后端调用 `workbuddy/deepseek-v4.1-flash` 生成摘要标题；实测标题为“Horizon Client首次安装后添加服务器”。

### 2.7 输入框粘贴图片

- 聊天输入框为原生 `<textarea>`，监听 `paste` 事件；从剪贴板读取 `image/*` 文件并生成本地预览。
- Chrome CDP 注入 64×64 PNG 粘贴事件后，`.image-preview img` 成功出现，`src` 为 `blob:` URL。

## 3. 首次部署踩坑与修正

| 问题 | 现象 | 修正 |
|---|---|---|
| Docker 构建 apt DNS 失败 | `Temporary failure resolving deb.debian.org` | 去掉不必要的 apt 依赖；MinerU 改用 pip 安装基础包 |
| Docker Hub 镜像拉取受限 | 镜像 mirror 401 | 复用本机已有 `python:3.11-slim`、`node:24-slim`、`nginx:alpine`；Kafka 单独 pull 成功 |
| MinerU 入口脚本重启循环 | `wait: Illegal option -n`（dash 不支持） | 改为 `wait "$API_PID" "$FP_PID"` |
| 1×1 mock PNG 被模型拒绝 | Magpie 400 "replace the image" | mock 图片替换为 64×64 有效 PNG；生产图片来自 MinerU 正常 |
| 前端状态列空白 | `el-tag` 动态类型未显示 | 改为显式 `.status-pill` 样式 |

## 5. 备注

- `rag-mysql` 的 `restart` 仍为 `"no"`（RAG 项目原约定）；飞牛重启后需先启动 `rag-mysql`/`rag-redis`/`rag-models`，再启动本 compose。
- 本项目的 `restart: unless-stopped` 只保证自身容器在 Docker 重启后自动拉起，不负责拉起 RAG 依赖。
