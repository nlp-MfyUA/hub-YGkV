# 部署运维（飞牛 fnOS）

## 1. 前置资源

| 资源 | 实测值 |
|---|---|
| 飞牛 | 192.168.124.88:62236，6 核 / 15 GiB / `/vol1` 剩余 67 GB |
| MySQL | `rag-mysql` 8.0.46，3306，utf8mb4 |
| rag-models | 容器名 `rag-models`，`/v1/embeddings`，512 维 |
| Magpie | 192.168.124.88:3425，模型 `workbuddy/deepseek-v4.1-flash` |
| 端口 | 8002 API、8082 Web、9094 Kafka 外部监听、8003 MinerU file-parse（容器内） |

## 2. 目录约定

飞牛项目目录：

```text
/vol1/1000/docker/rag-mm/
├── app/                后端源码（构建上下文）
├── frontend/           前端源码（构建上下文）
├── deploy/
│   ├── docker-compose.yml
│   ├── .env
│   └── mineru/
└── data/
    ├── uploads/
    ├── parsed/
    ├── chat_uploads/
    ├── kafka/
    └── mineru/
```

## 3. 创建 MySQL 库与用户

```bash
# 在飞牛宿主机执行；密码与 deploy/.env 的 MYSQL_PASSWORD 一致
docker exec -i rag-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" < deploy/mysql/init_rag_mm.sql
```

或进入容器：

```bash
docker exec rag-mysql mysql -uroot -p
CREATE DATABASE rag_mm CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'rag_mm'@'%' IDENTIFIED BY '<password>';
GRANT ALL PRIVILEGES ON rag_mm.* TO 'rag_mm'@'%';
FLUSH PRIVILEGES;
```

## 4. 启动 rag-models

```bash
docker start rag-models
docker ps --filter name=rag-models
curl -s http://127.0.0.1:8901/health
```

如果容器被 OOM 杀掉，先查看 `docker logs rag-models --tail 100`；必要时调整 RAG compose 的 mem_limit 或停掉不相关容器。

## 5. 构建与启动

```bash
cd /vol1/1000/docker/rag-mm/deploy

# 复制并填写环境变量
cp env.example .env
vi .env   # MYSQL_PASSWORD / MAGPIE_API_KEY 必须填

# 构建（首次 MinerU 镜像较慢）
docker compose build api web mineru

# 启动
docker compose up -d

# 查看
docker compose ps
docker compose logs -f api worker mineru kafka
```

## 7. 常用运维

```bash
docker compose logs -f worker
docker compose restart worker
docker compose down
docker compose up -d
```

## 8. MinerU 说明

- 镜像内运行两个进程：
  - `mineru-kit api-server --tier basic :8000`
  - `mineru-kit file-parse-server --api-url http://127.0.0.1:8000 :8003`
- 首次启动会下载 `basic` ONNX 模型（约 819 MB，存放 `./data/mineru`）。
- 飞牛无 GPU，`basic` 纯 CPU；若需要 `standard` VLM，请另接 GPU 主机。
