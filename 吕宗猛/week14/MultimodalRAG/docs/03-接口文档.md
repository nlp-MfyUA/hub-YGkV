# 接口文档

基础地址：`http://192.168.124.88:8002`（生产）或 `http://127.0.0.1:8002`（本机）。

## 1. 健康检查

`GET /api/health`

```json
{"status":"ok","database":"ok"}
```

## 2. 文档

### 2.1 多文件上传

`POST /api/documents/upload`

- Content-Type: `multipart/form-data`
- 字段：`files`（可重复，多个 PDF）

响应：

```json
[
  {"id":1,"file_name":"a.pdf","file_size":12345,"status":"pending","tier":"basic","page_count":null,"chunk_count":0,"image_count":0,"error_msg":null,"created_at":"...","updated_at":"...","parsed_at":null}
]
```

### 2.2 文档列表

`GET /api/documents` → 文档数组（按 id 倒序）。

### 2.3 SSE 状态流

`GET /api/documents/events`

`text/event-stream`，事件名 `documents`，data 为文档数组 JSON：

```text
event: documents
data: [{"id":1,"status":"parsing",...}]
```

### 2.4 文档详情

`GET /api/documents/{doc_id}`

### 2.5 重试

`POST /api/documents/{doc_id}/retry`（仅 failed/pending 可重试）

### 2.6 解析 Markdown

`GET /api/documents/{doc_id}/markdown` → `text/markdown`

### 2.7 图片资源

`GET /api/documents/{doc_id}/images/{file_name}` → 图片二进制

## 3. 聊天

### 3.1 创建会话

`POST /api/chat/sessions` → `{"id":1,"title":"新会话",...}`

### 3.2 会话列表

`GET /api/chat/sessions`，按 `updated_at` 倒序返回；前端左侧栏展示 `title`。

### 3.3 会话消息

`GET /api/chat/sessions/{session_id}/messages`

### 3.4 多模态提问

`POST /api/chat/ask`

每次问答完成后，后端调用 LLM 对当前对话生成不超过 20 个汉字的摘要，写回 `mm_chat_session.title`，响应中的 `session_title` 即最新标题。

- Content-Type: `multipart/form-data`
- 字段：
  - `session_id`: int，必填
  - `question`: string，可空（有图片时）
  - `image`: 可选图片文件

响应：

```json
{
  "session_id": 1,
  "session_title": "VDI 客户端登录指引",
  "answer": "文字...\n\n![图片](/api/documents/1/images/xxx.png)",
  "references": [{"doc_id":1,"file_name":"a.pdf","chunk_index":0,"score":0.83}],
  "images": [{"id":2,"url":"/api/documents/1/images/xxx.png"}]
}
```

## 4. 错误格式

```json
{"detail":"错误说明"}
```

常见状态码：400 参数错误、404 不存在、409 状态冲突、413 文件过大、503 Kafka/模型不可用。
