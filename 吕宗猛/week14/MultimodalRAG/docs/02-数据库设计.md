# 数据库设计（rag_mm）

## 1. 库与用户

```sql
CREATE DATABASE rag_mm CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'rag_mm'@'%' IDENTIFIED BY '<MYSQL_PASSWORD>';
GRANT ALL PRIVILEGES ON rag_mm.* TO 'rag_mm'@'%';
FLUSH PRIVILEGES;
```

## 2. 表结构

### 2.1 mm_document

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AUTO_INCREMENT | 文档 ID |
| file_name | VARCHAR(512) | 原始文件名 |
| stored_path | VARCHAR(1024) | 上传 PDF 路径 |
| file_size | BIGINT | 字节数 |
| status | VARCHAR(20) | pending / parsing / completed / failed |
| tier | VARCHAR(20) | MinerU 档位，默认 basic |
| page_count | INT NULL | 页数（预留） |
| chunk_count | INT | 切块数 |
| image_count | INT | 图片数 |
| markdown_path | VARCHAR(1024) | 解析后 Markdown 路径 |
| error_msg | TEXT | 失败原因 |
| created_at / updated_at / parsed_at | DATETIME | 时间 |

### 2.2 mm_chunk

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 块 ID |
| doc_id | BIGINT FK | 所属文档 |
| chunk_index | INT | 文档内序号 |
| content | TEXT | 文本内容，含 Markdown 图片标签 |
| token_count | INT | 估算 token 数 |
| image_ids | JSON | 本块引用的 mm_image.id 列表 |
| embedding | BLOB | float32 小端向量（512×4 字节） |
| created_at | DATETIME | 创建时间 |

### 2.3 mm_image

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 图片 ID |
| doc_id | BIGINT FK | 所属文档 |
| file_name | VARCHAR(512) | 图片文件名 |
| file_path | VARCHAR(1024) | 宿主/容器内绝对路径 |
| mime_type | VARCHAR(128) | MIME |
| width / height | INT NULL | 预留 |
| created_at | DATETIME | 创建时间 |

### 2.4 mm_chat_session

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 会话 ID |
| title | VARCHAR(255) | 默认“新会话”，首次提问后取问题前 60 字 |
| created_at / updated_at | DATETIME | 时间 |

### 2.5 mm_chat_message

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 消息 ID |
| session_id | BIGINT FK | 会话 |
| role | VARCHAR(20) | user / assistant |
| content | TEXT | 文本或 Markdown 回答 |
| image_path | VARCHAR(1024) | 用户上传图片路径 |
| image_ids | JSON | 助手回答引用的图片 ID |
| created_at | DATETIME | 时间 |

## 3. 索引

- `mm_document(status, id)`
- `mm_chunk(doc_id, chunk_index)`
- `mm_image(doc_id)`
- `mm_chat_message(session_id, id)`

## 4. 向量说明

MySQL 8.0 无原生 vector 类型；`mm_chunk.embedding` 用 BLOB 存 float32 小端数组，检索时在应用层解码并计算余弦相似度。数据量增大后可迁移到 Milvus/ES/MySQL 9 VECTOR。
