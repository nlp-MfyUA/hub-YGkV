## 2. 用例与结果

| 编号 | 用例 | 预期 | 实测结果 | 判定 |
|---|---|---|---|---|
| T1 | 上传 2 个 PDF | 返回 2 个 doc_id，状态 pending→parsing→completed | vdi-guide.pdf 859,469 B；tax-mindmap.pdf 49,424 B；两者均 completed | 通过 |
| T2 | 打开 SSE | 状态变化在 2 秒内推送到页面 | 一次上传捕获 4 个 documents 事件，依次出现 pending / parsing / completed | 通过 |
| T3 | 查看 Markdown | 图片标签指向 `/api/documents/{id}/images/...` | `![图片](/api/documents/3/images/page_0_image_0.jpg)`；图片接口 HTTP 200 image/jpeg | 通过 |
| T4 | 文本问答 | 回答包含引用来源 | VDI 指引问答返回 6 条 references | 通过 |
| T5 | 图文问答 | 回答中出现 PDF 原图，图文混排 | 回答内嵌 5–7 张 PDF 原图，答案分章节 | 通过 |
| T6 | 用户上传图片提问 | 模型理解图片并回答 | 64×64 红色 PNG + “这张图片是什么颜色？” → 回答“红色” | 通过 |
| T7 | 失败重试 | 失败文档可重新投递并完成 | 停止 MinerU 后上传 doc 6，worker 记录 ConnectError；启动 MinerU 后 `POST /api/documents/6/retry` → 200，最终 completed（1 chunk / 1 image） | 通过 |
| T8 | Kafka 断连 | api 上传返回 503 并标记失败 | 未实测 | 待补测 |
| T9 | 会话记录与标题 | 左侧显示历史会话；点击可加载消息；标题由 LLM 摘要生成 | 新建会话提问后标题变为“Horizon Client首次安装后添加服务器”；点击会话加载 2 条消息 | 通过 |
| T10 | 输入框粘贴图片 | Ctrl+V 粘贴截图后出现图片预览，可随问题发送 | Chrome CDP 注入 64×64 PNG 的 paste 事件，`.image-preview img` 出现且 `src` 为 blob URL | 通过 |

## 5. 已知限制

- `page_count` 暂未从 MinerU 结果中提取，显示为空。
- 纯图片 PDF（如思维导图）只能形成 1 个图片块，文本检索效果有限；图片仍会入库。
- 向量检索在应用内逐条计算余弦相似度，数据量大后需迁移向量库。
- 单用户演示，无登录与权限体系。
