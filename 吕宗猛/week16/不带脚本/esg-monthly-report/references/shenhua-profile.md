# 中国神华：研究起点和边界

默认主体为中国神华能源股份有限公司，A 股代码 601088、H 股代码 01088。执行时从公司和交易所当期资料重新核对身份、业务与上市信息。国家能源集团不是默认报告主体；集团政策或其他子公司行动只有能解释对上市公司的影响时才纳入，并标明关系待核实之处。

## 业务与技术议题

公司公开业务涉及煤炭、发电及运输等环节。以下是查询起点，不代表已发现公司问题，也不是每个月都要凑齐的栏目：

| 业务/能力 | 可研究的技术与证据议题 | 建议前需判断 |
| --- | --- | --- |
| 煤炭生产 | 能耗、甲烷与碳核算、水、扬尘、矿区生态、设备与人员安全 | 主体/矿区边界、规则适用、数据年份、成效来源 |
| 发电 | 排放、煤耗与能效、节水、环保监测、技改与低碳技术 | 机组和项目条件、系统边界、基线、运行约束 |
| 铁路、港口、航运等运输 | 燃料与电力、污染物、运输效率、作业安全 | 资产和运营控制边界、业务可比性 |
| 数据与披露 | 计量溯源、碳/能源/水台账、口径版本、证据归档、复核权限 | 公开资料只能提出核实/评估动作，不能断言内部数据缺陷 |
| 社会与治理 | 安全培训、承包商、供应链、员工、责任与审查流程 | 不把制度存在等同于执行成效；保留争议与负面事件 |

技术实践的迁移判断采用“相似场景、必要前提、系统边界、可验证收益、限制”五项。不能仅因同行宣称使用某技术就建议神华采购或改造，也不能从公开材料虚构预算、内部负责人和现有系统。
