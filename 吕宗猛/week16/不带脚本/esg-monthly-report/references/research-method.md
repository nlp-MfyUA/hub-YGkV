# 来源与检索策略

## 查询矩阵

为实际月份生成查询，不把示例年份写死。逐步使用搜索发现候选、打开原文、顺着引用找正式文件、对照公司边界。搜索日期过滤只是辅助，最终以原文日期为准。

| 线索 | 查询扩展 | 优先核验来源 |
| --- | --- | --- |
| 政策与披露 | 可持续发展报告、ESG、气候披露、碳市场、节能、环境、安全 + 月份/业务 | 主管部门、交易所、正式政策和附件 |
| 评级 | 公司全称/股票代码 + ESG rating/评级 + 机构/月份 | 评级机构、明确归属的公司披露；付费页只能记覆盖缺口 |
| 标准 | 核算、鉴证、温室气体、能源/水/安全数据、可持续披露 + 发布/修订 | 标准制定方、监管及其原始文件 |
| 公司事件 | 神华/中国神华/601088/01088 + 技改、项目、安全、污染、水、生态、供应链 | 公司及交易所公告；主管部门的行政/事故资料 |
| 行业与同行 | 煤炭、燃煤发电、铁路/港口/航运 + 节能、监测、甲烷、生态、安全、低碳 | 同行业企业原始披露、政府/行业机构；媒体用于发现线索 |

在煤炭与能源业务中，不能只搜“ESG”；重要工程、安全和环保事件可能不含该词。英文用于国际来源和评级补充，但是否进入报告取决于公司关联性。

## 来源层级和核验

### 联网能力与回退

优先使用当前会话提供的联网搜索与正文读取工具。若没有内置搜索，可使用当前环境可用的浏览器或本地文件；不得把搜索摘要当作原文核验。所有检索查询、来源、获取时间和失败原因记入 evidence.json 的 coverage。快照获取成功只证明取得材料，正文中的日期、主体、摘录与数字仍须核验。无文本层 PDF 需另行 OCR 或通过文档/浏览器实际阅读；登录、访问限制及验证码页不构成有效事实证据。

正式监管文件优先于转述；公司公告能证明公司作出的披露，不自动证明所有效果。评级机构的原始输出优先，企业引用评级时保留“公司披露称”的归属。媒体原文可用于行业判断或争议线索，重大监管适用性仍须正式来源。

优先检查：[国务院](https://www.gov.cn/)、[证监会](https://www.csrc.gov.cn/)、[生态环境部](https://www.mee.gov.cn/)、[发展改革委](https://www.ndrc.gov.cn/)、[国家能源局](https://www.nea.gov.cn/)、[应急管理部](https://www.mem.gov.cn/)、交易所及与事件有关的地方主管部门。名单是起点，记录实际打开的页面，而非把列出机构视为检索完成。

内地和香港分别核实主体、版本及过渡安排。ISSB/IFRS、GRI 等国际框架来自制定方；自愿参考或国际趋势不得写成公司的强制义务。标准可解释数据要求，但具体认证或鉴证范围需原文证据。

每份候选材料处理以下问题：

1. 这是原创、转载、更新还是更正？标题日期、URL 年份与正文日期是否一致？
2. 发生时间、发布时点、规则生效和指标统计期各是什么？本月事实为何按当前日期口径纳入？
3. 信息属于上市公司、集团、子公司或同行？与客户的影响关系是否可证？
4. 核心语句和数字能定位到正文段落或 PDF 页码吗？数字的单位、边界、方法是否清楚？
5. 是否存在相反证据或不同来源口径？若无法裁决，降低结论强度并列缺口。

网页无法打开时，尝试发布方目录、官方附件或另一官方发布渠道。有授权且可用的浏览器可以补充读取。仍只有摘要时设为线索，不自行生成原文摘录，不把工具失败伪装成无更新。

## 停止与重大性

检索需覆盖五项：政策、评级、标准、公司、行业/同行。每项记录查询、已检查来源及剩余缺口。重要事实存在冲突或原文缺失时继续定向核实；重要来源已检查、新增查询只返回重复/低相关信息时可停止，并说明边界。

不承诺互联网全量。按合规影响、技术/人员/环境风险、业务相关性和可行动性选择正文；背景与未核实线索放附录。先寻找推翻主要判断的证据，再形成建议，不能用正面案例掩盖重要风险。
