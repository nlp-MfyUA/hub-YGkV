# 检索与证据策略

## 范围与覆盖

中国全国公开采购是首批范围，包含中央采购和地方采购、政府和企业采购。全国覆盖不意味着全部公告可取得；列出实际访问的来源、检索时间窗和地区，说明未覆盖地区及受登录、验证码、附件缺失或索引限制影响的渠道。搜索摘要仅作发现线索。

默认历史窗口是研究日期向前24个日历月，起止日期均包含。主历史成交统计按原文核验的已确认中标/成交公告 `published_date`，不是实际成交日期或转载日期；显式指定 `--date-basis award_date` 时才按实际成交日期。已有公告新发布更正可进入监控，但不能因更正日期把旧成交算成本期新成交。

## 首批来源入口

### 实际联网路径

优先使用本会话真实提供的搜索与网页/PDF读取工具。无内置搜索时可用安装包 `scripts/search_web.py` 发现线索，用 `scripts/fetch_sources.py` 保存原始公告、正文文本、哈希和获取元数据；源码工作区的共用脚本在项目根 `scripts/`，安装时复制进各 Skill。

```text
python "<skill>/scripts/search_web.py" --query "<地区/业务/月份 中标或招标>" --engine auto --limit 10 --output "<data>/search.json"
python "<skill>/scripts/fetch_sources.py" --url "<官方公告URL>" --id S001 --output-dir "<data>/source-snapshots"
```

确需使用环境已配置的代理时加 `--proxy`。HTTP 搜索受验证码、JavaScript 或解析限制，或结果明显不符时，转用当前可用的浏览器/官方公告目录。首次使用浏览器先阅读工具返回文档；若宿主提供可用隐藏浏览器，可经其检索 Google 并读取官方原文，否则采用实际可用的浏览器入口。遇到同一验证页停止重复请求，不尝试绕过验证、不导入账号状态。来源获取失败与搜索无结果分别记录。

PDF 提取需要 `pypdf`，可使用宿主提供的文档运行时；无文本层材料需实际 OCR 或文档阅读。获取工具不能替研究者核对日期、项目身份、标包和金额。验证码页、搜索摘要、无法读取的附件不能支持确定成交金额或投标资格判断。

每次研究重新验证入口是否可用；入口不是未经核验的接口或采集覆盖承诺。

## 查询词与分层

| 层级 | 业务词举例 | 需核实的边界 |
| --- | --- | --- |
| `service` 专业服务 | ESG报告、可持续发展报告、评级、鉴证、碳盘查、碳核算、碳足迹、双碳规划、环境咨询 | 报告编制与一般宣传；已确定成交与候选公告 |
| `software_data` 软件与数据 | 碳管理平台、能耗管理、环境监测平台、碳排放统计、数据治理 | 软件服务与设备采购混合；许可证金额是否一次性 |
| `equipment_engineering` 设备与工程 | 节能改造、能效提升、余热回收、污染治理、污水处理、生态修复、环保工程 | 合同额可能含设备、施工与运维，不能解释为咨询收入 |
| `mixed` 混合项目 | 咨询+平台+设备、设计采购施工、综合监测运维 | 原文无可靠分项金额时只计整体，不自拆金额 |

先以这些词与“招标/采购/中标/成交/更正/终止/合同”组合，再按采购方、地区、来源与月份扩展。采用“宽发现、原文判相关”的方式：纯标题关键词匹配不替代项目需求判断。纳入理由应指向实际减排、治理、监测、披露或相关工程任务；排除无业务关联的同名词、仅营销新闻或已无效线索。

## 检索展开与停止

1. 从全国入口与采购方原文开始，按四类业务扩展。
2. 用地区和历史月份补充检索；查询遇到结果上限时细分时间，不把搜索条数当成结果全集。
3. 找到项目后跟踪候选、结果、合同、更正和撤销；记录原编号和标包。
4. 对金额较大、核心结论、明显冲突及近期截止的公告优先核验附件。
5. 在研究预算内继续补齐影响结论的证据；若新增检索主要重复或关键来源持续不可访问，交付覆盖说明和缺口，不把缺失编成事实。

来源台账应记录成功、仅搜索线索、访问失败和成功未发现相关项目。已知官方公告回测用于验证检索方法，不能外推为全国召回率。没有可核实市场总体分母时，不报告“覆盖率达到 X%”。

## 日期与主体

- 同时保存公告日期、实际成交日期、截止时间和检索时间；正文与附件冲突时标记需核实。
- 日期只有月份或模糊“近期”时不能补造具体日。无实际成交日期可正常进入公告发布日期主统计，明确这不是实际成交日期；按实际成交日期模式筛选时，缺失日期单列不入主统计。
- 采购人、代理机构、中标主体分别记录。集团和子公司不能因名称相近自动归并。
- 联合体保留全体名单，投标资格和资金条件只根据原文，不能替用户判断具备资格。
