# langchain的工具调用
## 与llm function call区别
```
langchain的工具调用，模型会根据系统提示词的流程，多次自动调用
llm function call，模型只会根据提示词，返回tool call列表，需要再去手动调用，知道tool call列表为空为止
```

## 影响工具调用的速度的因素
```
1、模型响应速度
2、工具内部处理耗时
3、系统提示词、人工提示词中关于系统流程的描述
```

# 01-intent-classify流程图解析
## 请求
```
1、/v1/text-cls/regex -> 
  说明：
      字符串包含关键字,获取关键字对应的分类
      model_for_regex函数(既可以接收str，也可以接收字符串列表)
      遍历配置中的REGEX_RULE,如果字符串包含关键字，则追加字典key
      
2、/v1/text-cls/tfidf
  说明：
      先分词，再使用tifdf模型识别并分类
      使用jieba分词，并且不在停止词列表中，就使用模型识别并分类
  
3、/v1/text-cls/bert
  说明：
      加载预训练的模型权重，对传入的文本进行tokenizer的转换。
      输出各分类的logits分数，再获取最大logits分数，得到对应分类id
      根据分类id，及分类顺序，获取分类名称并返回
  注意：
      此分类，对list[str] 不适用
  
4、/v1/text-cls/gpt
  说明：
      加载tfidf训练的模型
      使用tfidf的TfIdfVectorizer向量转换器，根据请求的文本，转为向量矩阵
      根据转换后的向量矩阵，在原训练集中计算相似度，并由大到小获取相似度最高的前10条
      将相似度最高的前10条、请求的文本、训练集中所有的分类列表，传给大模型
      并给大模型一个意图识别的系统提示词，让模型根据分类列表，相似度高的10条数据，分析请求的文本属于哪种分类
      得到大模型的响应后，返回给用户
```
	
	
## 备注
```
tfidf过程：
  训练：
    1、读取源数据(dataset.csv)的第一列,并循环遍历每一行，使用jieba分词
    2、排除stopwrods中的词
    3、再使用TfidfVectorizer(文本转向量的工具)，以单个词作为特征，默认保留字符>=2的，对步骤2处理后的词进行tfidf向量化
    4、向量结果为[训练样本条数,有效特征词数]的矩阵，即每行的每个有效特征词出现的tfidf值
    5、根据源数据的第二列，进行分类训练，得到每个词基于每种分类的权重(权重越大，则越支持该分类;越小,则越不支持该分类)
  预测：
    1、新输入的文本，jieba分词，并且排除stopwords中的词
    2、加载训练模型，获取这句话的每个词对应的tfidf向量矩阵
    4、再使用LinearSVC预测这些词对应的分类
    3、综合得到这句话属于哪个分类
bert过程：
  训练：
    按批次读取源数据，按指定的batch_size批次大小和epoch轮数进行训练
    每条样本，包含文本和对应的分类标签
    文本使用tokenizer转换input_ids和attention_mask(设置合适的max_length,以便提高训练速度)
    模型前向预测得到logits，再和正确的标签进行交叉熵，得到loss值。
    判断loss值，loss值越大，则越偏离
    根据训练批次和更新设置，进行梯度更新
    训练epoch轮数后，选择验证集表现最好的checkpoint，并保存最优的模型权重
  预测：	
    输入新文本
    加载训练过的模型权重，使用tokenizer转换为input_ids和attention_mask
    得到新文本针对于各分类的logits分数
    按文本分类，获取最大的logits分数
    再根据分类id，找到对应的分类名称
```
