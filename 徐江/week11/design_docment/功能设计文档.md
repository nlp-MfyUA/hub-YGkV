## 1. 文档目的与范围

## 3. 用户角色与权限总则

| 角色 | 功能范围 |
|---|---|
| 普通用户 | 登录、聊天提问、问数、知识库问答、手动联网、查看个人历史 |
| 部门用户 | 普通用户能力 + 仅检索本部门及公共知识库 |
| 管理员 | 用户/角色/部门管理、知识库管理、MCP 配置、任务管理、审计查看 |
| 数据管理员 | 数据源与表白名单、SQL 审核规则、表级权限配置 |

**权限总则**：

1. 未登录不能访问业务页面；
2. 普通用户不可见管理后台入口；
3. 知识库检索自动附加部门过滤；
4. 问数只允许访问授权表，未授权表不进入 Schema 候选；
5. 所有查询、知识库检索、MCP 调用、联网检索、定时任务执行均写审计日志。

## 4. F1 登录与权限

### 4.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F1-1 | 账号密码登录 | P0 | 自建用户体系 |
| F1-2 | 登录态保持与登出 | P0 | 支持超时登出 |
| F1-3 | 用户管理 | P0 | 新增、编辑、禁用、分配角色与部门 |
| F1-4 | 角色管理 | P0 | 普通用户、部门用户、管理员、数据管理员 |
| F1-5 | 部门管理 | P0 | 部门树、部门成员 |
| F1-6 | 知识库部门过滤 | P0 | 仅检索本部门及公共知识 |
| F1-7 | 数据表级权限 | P0 | 按角色/部门授权可查询表 |
| F1-8 | SSO 对接 | P2 | 后续迭代 |

### 4.2 页面与交互

- **登录页**：用户名、密码、登录按钮、错误提示；
- **用户管理页**：用户列表、搜索、新增/编辑/禁用、分配角色与部门；
- **角色管理页**：角色列表、权限项勾选；
- **部门管理页**：部门树、成员列表、添加/移除成员；
- **表权限配置页**：选择数据源 → 选择表 → 授权角色/部门。

### 4.3 权限规则

- 密码错误统一提示“用户名或密码错误”；
- 禁用用户不能登录；
- 普通用户访问管理 URL 时跳转无权限页；
- 无表权限用户问数时提示联系管理员授权。

### 4.4 异常流程

| 场景 | 处理 |
|---|---|
| 密码错误 | 提示“用户名或密码错误” |
| 账号禁用 | 提示“账号已禁用，请联系管理员” |
| 登录超时 | 跳转登录页并保留原地址 |
| 无表权限 | 提示“无可查询的数据表，请联系管理员授权” |
| 部门未配置 | 默认只能访问公共知识库 |

### 4.5 验收用例

1. 正确账号密码可登录，错误密码有提示；
2. 普通用户看不到管理后台入口；
3. A 部门用户检索不到 B 部门私有知识；
4. 未授权表的问数请求被拒绝并提示；
5. 禁用用户无法登录。

## 5. F2 会话与意图编排

### 5.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F2-1 | 新建会话 | P0 | 每个会话独立上下文 |
| F2-2 | 会话列表与历史 | P0 | 查看本人历史会话 |
| F2-3 | 意图识别与路由 | P0 | 问数、知识库、MCP、联网、普通问答 |
| F2-4 | 多轮上下文 | P0 | 支持追问，如“按月份拆开” |
| F2-5 | 手动模式切换 | P1 | 用户可强制指定问数/知识库/联网 |
| F2-6 | 消息重试与重新生成 | P1 | 对失败回答重试 |

### 5.2 页面与交互

- **聊天主页面**：左侧会话列表，中间消息流，底部输入框；
- 输入框上方提供模式开关：自动、问数、知识库、联网；
- 每条回答显示：回答内容、SQL（如有）、表格/图表、引用来源、耗时、操作按钮；
- 消息操作：复制、重新生成、查看 SQL、导出。

### 5.3 路由规则

| 用户意图 | 路由 |
|---|---|
| 问数据、统计、趋势、排名 | 问数 |
| 问制度、口径、文档、历史 SQL | 知识库 |
| 需要外部工具能力 | MCP |
| 用户手动开启联网且问题需要外部信息 | 联网检索 |
| 无法判断 | 普通问答并提示可切换模式 |

### 5.4 异常流程

| 场景 | 处理 |
|---|---|
| 意图无法识别 | 返回澄清问题，提供模式按钮 |
| 上下文过长 | 截断早期消息并提示 |
| 上游模型超时 | 提示重试，不丢失用户问题 |
| 会话不存在 | 返回会话列表 |

### 5.5 验收用例

1. 新建会话后消息独立；
2. “查一下上月销售额”路由到问数；
3. “报销制度怎么规定”路由到知识库；
4. 追问“按部门拆开”能继承上一轮问数上下文；
5. 手动切换知识库模式后不再走问数。

## 6. F3 自然语言问数

### 6.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F3-1 | Schema 检索 | P0 | 根据问题检索相关表、字段、指标口径 |
| F3-2 | SQL 生成 | P0 | 基于授权 Schema 生成只读 SQL |
| F3-3 | SQL 展示 | P0 | 展示 SQL，可折叠/复制 |
| F3-4 | SQL 执行 | P0 | 只读执行并返回结果 |
| F3-5 | 表格展示 | P0 | 结果表格、分页、字段名 |
| F3-6 | 图表建议与渲染 | P0 | 柱状图、折线图、饼图等基础图表 |
| F3-7 | 结果解释 | P0 | 用自然语言解释查询结果 |
| F3-8 | 结果导出 | P1 | 导出 CSV |
| F3-9 | 查询失败重试 | P1 | 根据错误信息修正 SQL 后重试一次 |

### 6.2 页面与交互

- 用户输入问题后，展示处理步骤：检索 Schema → 生成 SQL → 审核 → 执行 → 生成图表/解释；
- SQL 区块默认折叠，可展开复制；
- 表格支持排序、分页；
- 图表支持切换类型；
- 回答底部展示“数据来源表”和“执行耗时”。

### 6.3 业务规则

- 只允许生成 `SELECT` 类只读 SQL；
- 只能使用当前用户有权限的表；
- 结果为空时给出“未查询到数据”并附 SQL；
- 指标口径优先使用知识库中的口径说明；
- 图表类型根据结果字段自动建议，用户可手动切换。

### 6.4 异常流程

| 场景 | 处理 |
|---|---|
| 无相关表 | 提示补充表名或联系管理员授权 |
| SQL 生成失败 | 展示失败原因，允许重新生成 |
| SQL 审核不通过 | 展示审核原因，不执行 |
| SQL 执行报错 | 展示脱敏错误信息，允许重试一次 |
| 结果过大 | 限制返回行数并提示导出 |
| 图表无法生成 | 降级为表格展示 |

### 6.5 验收用例

1. “上个月各区域销售额排名”生成可执行 SQL、表格和柱状图；
2. SQL 仅包含授权表；
3. 无权限表不出现在 Schema 候选；
4. 空结果有明确提示；
5. 执行报错不泄露数据库敏感信息；
6. 结果可导出 CSV。

## 7. F4 SQL 安全审核

### 7.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F4-1 | 只读校验 | P0 | 禁止 INSERT/UPDATE/DELETE/DDL |
| F4-2 | 表白名单校验 | P0 | 只允许白名单及授权表 |
| F4-3 | 敏感函数/关键字限制 | P0 | 禁止危险函数与多语句 |
| F4-4 | 高危 SQL 前台确认 | P0 | 高风险查询需用户确认后执行 |
| F4-5 | 审核结果展示 | P0 | 展示通过/拒绝原因 |
| F4-6 | 后台人工审核队列 | P2 | 后续迭代 |

### 7.2 交互流程

1. SQL 生成后先自动审核；
2. 审核通过 → 直接执行；
3. 审核为高危 → 弹出确认框，展示 SQL、风险原因、确认/取消；
4. 审核拒绝 → 不执行，展示原因并允许重新提问。

### 7.3 规则定义

| 规则 | 结果 |
|---|---|
| 非 SELECT 语句 | 拒绝 |
| 多语句 | 拒绝 |
| 非白名单表 | 拒绝 |
| 无权限表 | 拒绝 |
| 全表扫描/无时间条件的大表查询 | 高危，需确认 |
| 含敏感函数或系统表 | 拒绝 |
| 结果行数可能过大 | 高危或限制行数 |

### 7.4 异常流程

| 场景 | 处理 |
|---|---|
| 审核服务异常 | 默认拒绝执行并提示 |
| 用户取消高危确认 | 不执行，保留 SQL |
| 确认超时 | 视为取消 |
| 规则误判 | 管理员可调整规则，用户可重新提问 |

### 5.5 验收用例

1. `DELETE` 语句被拒绝；
2. 非白名单表查询被拒绝；
3. 大表无时间条件查询弹出确认；
4. 取消确认后不执行；
5. 审核拒绝原因可见。

## 8. F5 知识库

### 8.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F5-1 | 文档上传 | P0 | 支持 PDF、Word、TXT、Markdown |
| F5-2 | 文档解析与切分 | P0 | 解析文本并切分 |
| F5-3 | 向量化与索引 | P0 | 写入向量索引 |
| F5-4 | 部门标签 | P0 | 文档绑定部门或公共 |
| F5-5 | 知识库问答 | P0 | 基于检索结果回答 |
| F5-6 | 引用溯源 | P0 | 回答附文档名、片段、位置 |
| F5-7 | 文档管理 | P0 | 列表、删除、重建索引 |
| F5-8 | 历史 SQL/表结构入库 | P1 | 作为知识库内容 |
| F5-9 | 定时更新索引 | P1 | 与 F8 联动 |

### 8.2 页面与交互

- **知识库管理页**：文档列表、上传、部门选择、状态（解析中/已索引/失败）、重建索引、删除；
- **聊天知识库回答**：回答正文 + 引用卡片；点击引用展开原文片段；
- 引用显示：文档名、部门、片段、相似度。

### 8.3 权限规则

- 上传时选择“公共”或具体部门；
- 检索时只返回公共 + 当前用户部门文档；
- 管理员可管理所有文档；
- 部门用户不能删除其他部门文档。

### 8.4 异常流程

| 场景 | 处理 |
|---|---|
| 文件格式不支持 | 提示支持格式 |
| 解析失败 | 标记失败，允许重试 |
| 无检索结果 | 提示未找到，可建议开启联网 |
| 引用缺失 | 回答需标注“无直接引用” |
| 文档被删除 | 引用失效提示 |

### 8.5 验收用例

1. 上传 PDF 后状态变为已索引；
2. 提问能返回带引用回答；
3. A 部门用户检索不到 B 部门文档；
4. 删除文档后不再被检索；
5. 无结果时有明确提示。

## 9. F6 MCP 工具调用

### 9.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F6-1 | MCP Server 配置 | P0 | 管理员配置外部 MCP Server |
| F6-2 | 工具发现 | P0 | 列出可用工具及描述 |
| F6-3 | 工具选择与调用 | P0 | 根据意图选择工具并调用 |
| F6-4 | 调用结果回填 | P0 | 结果进入回答 |
| F6-5 | 调用日志 | P0 | 记录工具、参数、结果状态 |
| F6-6 | 工具启停 | P1 | 管理员可启用/禁用 |

### 9.2 页面与交互

- **MCP 配置页**：Server 列表、名称、地址、状态、测试连接、启停；
- 聊天中调用 MCP 时显示“正在调用工具：xxx”；
- 结果展示工具返回内容，并标注来源工具。

### 9.3 规则

- 只调用已启用且连接正常的 Server；
- 工具调用参数需经过校验；
- 调用失败不阻塞整体回答，降级说明失败原因；
- 所有调用写审计日志。

### 9.4 异常流程

| 场景 | 处理 |
|---|---|
| Server 不可达 | 提示工具不可用，降级回答 |
| 工具不存在 | 重新发现工具或提示 |
| 参数校验失败 | 不调用并提示 |
| 调用超时 | 中断并提示 |
| 返回格式异常 | 展示原始摘要并记录日志 |

### 9.5 验收用例

1. 管理员可添加并测试 MCP Server；
2. 用户问题能触发至少 1 个工具调用；
3. 调用结果出现在回答中；
4. Server 不可达时有降级提示；
5. 审计日志可查工具调用记录。

## 10. F7 联网检索

### 10.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F7-1 | 联网开关 | P0 | 用户手动开启 |
| F7-2 | 搜索 API 调用 | P0 | 通用搜索 API |
| F7-3 | 结果汇总 | P0 | 汇总标题、摘要、链接 |
| F7-4 | 来源引用 | P0 | 回答附来源链接 |
| F7-5 | 与知识库/问数结合 | P1 | 综合回答 |
| F7-6 | 自动触发 | P2 | 后续迭代 |

### 10.2 页面与交互

- 输入框上方“联网”开关，默认关闭；
- 开启后回答显示“联网检索结果”区块；
- 来源展示标题、域名、链接、摘要；
- 可关闭联网后继续提问。

### 10.3 规则

- 未开启联网不调用外部搜索；
- 搜索结果需标注来源；
- 外部结果与内部知识冲突时分别展示；
- 记录联网检索审计日志。

### 10.4 异常流程

| 场景 | 处理 |
|---|---|
| 搜索 API 失败 | 提示联网检索失败，继续内部回答 |
| 无结果 | 提示未检索到外部信息 |
| 结果过多 | 取 TopN 并摘要 |
| 链接不可访问 | 保留标题与摘要 |

### 10.5 验收用例

1. 未开启联网不调用搜索；
2. 开启后返回带来源结果；
3. 搜索失败不影响内部回答；
4. 来源链接可点击；
5. 审计日志记录联网查询。

## 11. F8 定时任务

### 11.1 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F8-1 | 任务创建 | P0 | 名称、类型、Cron、参数 |
| F8-2 | 定时报表推送 | P0 | 执行报表 SQL 并推送 |
| F8-3 | 知识库索引更新 | P0 | 定时重建/更新索引 |
| F8-4 | 手动触发 | P0 | 立即执行一次 |
| F8-5 | 任务启停 | P0 | 启用/暂停 |
| F8-6 | 执行日志 | P0 | 状态、耗时、结果、错误 |
| F8-7 | 推送渠道 | P0 | Webhook，邮件 P1 |
| F8-8 | 告警/异常检测 | P2 | 后续迭代 |
| F8-9 | 自然语言问答复盘 | P2 | 后续迭代 |

### 11.2 页面与交互

- **任务管理页**：任务列表、状态、Cron、下次执行时间、操作（编辑/启停/手动执行/日志）；
- **任务编辑页**：选择任务类型、配置 SQL 或知识库、Cron、推送方式；
- **执行日志页**：执行时间、状态、耗时、输出摘要、错误信息。

### 11.3 规则

- 任务只能由管理员/数据管理员创建；
- 报表任务复用 SQL 审核规则；
- 任务执行结果写审计日志；
- 失败任务保留错误信息，可手动重试；
- Demo 单实例运行，同一任务不并发执行。

### 11.4 异常流程

| 场景 | 处理 |
|---|---|
| Cron 非法 | 保存时校验并提示 |
| SQL 审核失败 | 任务失败并记录原因 |
| 推送失败 | 记录失败，支持重试 |
| 索引更新失败 | 保留旧索引并告警 |
| 任务执行超时 | 标记超时并记录 |

### 11.5 验收用例

1. 创建每分钟执行的报表任务并手动触发；
2. 任务执行日志可查；
3. 知识库索引更新任务成功；
4. 非法 Cron 无法保存；
5. 推送失败有错误记录。
