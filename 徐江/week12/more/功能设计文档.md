## 2. 前端功能

### F-01 摄像头权限与预览

- 页面加载显示"开启摄像头"主按钮。
- 点击后调用 `navigator.mediaDevices.getUserMedia({ video: { facingMode: { ideal: 'environment' }, width: { ideal: 1920 }, height: { ideal: 1080 } } })`。
- 流绑定到 `<video autoplay playsinline muted>`，容器内自适应。
- 权限被拒 / 无设备 / 非安全上下文 → 显示降级提示条，引导使用 F-04。
- 页面切后台时自动 `track.stop()` 释放摄像头，回前台可重新申请。

### F-02 拍照捕获与压缩

- 点击"拍照"：创建离屏 `canvas`，尺寸按视频实际分辨率等比缩放到长边 ≤ 1600 px。
- `ctx.drawImage(video, 0, 0, w, h)` → `canvas.toBlob(cb, 'image/jpeg', 0.85)`。
- 得到 `Blob` 后：显示静态预览图、禁用"拍照"、启用"重拍 / 上传分析"。
- 记录压缩前后字节数，便于调试。

### F-03 上传与结果渲染

- `FormData` 追加 `image`（Blob，文件名 `capture-<timestamp>.jpg`）。
- `fetch('/api/analyze', { method: 'POST', body: formData })`。
- 加载态：按钮转圈 + 文案"识别中…"，超过 15 s 显示"仍在识别，请稍候"，超过 45 s 前端主动 `AbortController.abort()`。
- 成功渲染：
  - **等级色块**：高风险 `#D93025`、中风险 `#F29900`、低风险 `#1A73E8`、无风险 `#188038`、非楼道 `#5F6368`。
  - **置信度徽标**：high 实心、medium 描边、low 灰色。
  - **evidence** 段落。
  - **signals 列表**（若模型返回多个信号）：每条含类型、等级、细节。
  - **法规提示**（按等级映射的固定文案）。
  - **原始返回**：`<details>` 可折叠，展示格式化 JSON。
  - **裁决覆盖标记**：若 `arbiter_override` 为 true，显示"服务端已按取最高规则修正等级"的小提示。
- 失败渲染：红色错误条 + 错误信息 + "重试"按钮。

### F-04 相册上传降级通道

- 常驻 `<input type="file" accept="image/*" capture="environment">`。
- 选中文件后走与 F-02 相同的压缩管线（`createImageBitmap` + canvas），再走 F-03。

### 前端状态机

```
idle → requesting_camera → previewing → captured → uploading → rendering → done
                ↓                ↓            ↓
            camera_denied    (可重拍)      upload_error → 可重试
```

## 3. 后端功能

### F-05 图片接收与校验

- 端点：`POST /api/analyze`，`UploadFile` 字段名 `image`。
- 校验顺序：存在性 → MIME ∈ {`image/jpeg`,`image/png`,`image/webp`} → 大小 ≤ `MAX_IMAGE_MB`（默认 8）→ 用 Pillow 读取尺寸，最小边 ≥ 224。
- 校验失败返回 422 / 413，`detail` 为中文可读信息。

### F-06 Prompt 构造

系统提示词必须包含以下区块（顺序固定）：

1. **角色**："你是住宅楼道消防安全风险识别助手，只依据图像中可见证据判断。"
2. **场景分类**：先输出 `scene_type`，枚举五值，附判定要点。
3. **五级判据**：逐条列出，含"不计入堆物的对象"白名单。
4. **电动车分场景规则**：明确 stairwell/corridor/elevator 内电动车即高风险；garage_passage 内停放不单独判高风险，但飞线充电与堵塞通道按对应规则。
5. **冲突规则**：多信号取最高；单信号直接输出。
6. **图像质量兜底**：无法辨识 → 非楼道 + low。
7. **输出格式**：严格 JSON，给出一份完整示例，字段含 `scene_type`、`risk_level`、`confidence`、`evidence`、`signals`（数组，元素含 `type`/`level`/`detail`）。
8. **禁止项**：禁止输出 JSON 以外的任何文字；禁止编造图像中不存在的物体；evidence 必须引用可观察线索。

用户消息：`{"type":"text","text":"请分析这张图片中的楼道消防风险，严格按系统要求输出 JSON。"}` + `{"type":"image_url","image_url":{"url":"data:image/jpeg;base64,..."}}`。

### F-07 模型调用与结果解析

- `VisionProvider` 抽象方法：`async def analyze(image_b64: str, system_prompt: str, user_text: str) -> RawResult`。
- 超时：`TIMEOUT_S`（默认 30），`MAX_RETRIES=1`，仅对网络错误与 5xx 重试。
- 解析容错：
  1. 去除首尾空白；
  2. 若以 ``` 开头，剥离围栏；
  3. 定位第一个 `{` 与最后一个 `}`，截取子串；
  4. `json.loads`；
  5. Pydantic 校验；`risk_level` / `scene_type` 不在枚举 → 解析失败。
- 解析失败返回 502，`detail` 含失败原因，不把原始文本当结果返回。

### F-08 多信号裁决

- 输入：模型返回的 `signals[]` 与自报 `risk_level`。
- 规则：等级权重 高=3、中=2、低=1、无=0；取 `max(weight)` 对应等级。
- 若 `signals` 为空或缺失：信任模型自报等级，`arbiter_override=false`。
- 若裁决结果 ≠ 模型自报：以裁决为准，`arbiter_override=true`，日志记录两者。
- `非楼道` 不参与权重比较：若 `scene_type == non_corridor`，直接输出非楼道，忽略 signals。

### F-09 健康检查与配置自检

- `GET /api/health` → `{ status, provider, model, base_url_configured: bool, api_key_configured: bool }`。
- `GET /api/config` → `{ provider, model, max_image_mb, timeout_s }`（不含密钥）。
- 启动时 `lifespan` 钩子检查必填环境变量，缺失则日志 ERROR 并拒绝启动。

### F-10 请求日志

- 每次 `/api/analyze` 记录：`request_id`、`filename`、`size_bytes`、`provider`、`model`、`latency_ms`、`risk_level`、`arbiter_override`、`parse_ok`。
- **不记录**图片内容、Base64、API Key。

## 4. 评测功能

### F-11 批量评测与混淆矩阵

- `eval/dataset/labels.csv`：`filename,true_label`，`true_label` ∈ 五类。
- `python eval/run_eval.py --dataset eval/dataset --provider qwen --out eval/report.md`。
- 输出：
  - 总体准确率；
  - 5×5 混淆矩阵（markdown 表格）；
  - 各类 precision / recall / F1；
  - 错误样本清单（文件名 + 真实 + 预测 + evidence 摘要），便于人工分析；
  - 平均延迟。
- 支持 `--limit N` 抽样、`--provider` 覆盖、`--concurrency K` 并发（默认 1，避免触发限流）。

### F-12 连通性自检脚本

- `python scripts/check_provider.py --provider deepseek`。
- 内置一张最小测试图（程序生成 64×64 纯灰 JPEG），发起一次最小请求，打印 HTTP 状态、耗时、原始返回前 500 字符。
- 失败时打印诊断建议：检查 `base_url`、`model`、`api_key`，或切换 `--provider qwen`。

## 5. 错误处理矩阵

| 场景 | 后端 | 前端 |
|---|---|---|
| 格式不支持 | 422 `unsupported_image_type` | "请上传 JPEG/PNG/WebP" |
| 超过大小 | 413 `image_too_large` | "图片过大，请重拍" |
| 尺寸过小 | 422 `image_too_small` | "图片过小，请重拍" |
| 模型超时 | 504 `model_timeout` | "识别超时，请重试" |
| 模型 5xx | 502 `model_upstream_error` | "识别服务异常，请稍后重试" |
| 输出非 JSON | 502 `model_output_unparseable` | "识别结果异常，请重试" |
| 枚举越界 | 502 `invalid_enum` | 同上 |
| 未配置密钥 | 503 `provider_not_configured` | "服务未配置" |
| 网络中断 | — | `fetch` reject → "网络异常" |

   ├─ 成功 → [预览] → [拍照] → [静态预览] → [上传分析] → [加载] → [结果]

[结果页] → [展开原始返回] → 查看 JSON
```
