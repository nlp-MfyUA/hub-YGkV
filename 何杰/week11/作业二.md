# 1、项目设计文档
## 1.1 文档概述
| 项目 | 内容 |
| ---- | ---- |
| 文档名称 | ChatBI / Data Agent 项目设计文档 |
| 文档版本 | V1.0 |
| 面向角色 | 产品、开发、授课老师、项目评审 |
| 项目定位 | 对话式智能数据分析Agent（ChatBI），用户通过自然语言完成自助数据分析 |
| 关联前置项目 | 基于 chinook.db 的 SQL Agent、MCP 自定义工具调用 |

## 1.2 项目背景
传统BI平台存在使用门槛高的问题：业务人员需要掌握维度、指标、SQL语法、图表配置才能完成分析。
日常取数需求大量堆积在数据开发，沟通成本高、响应慢。
ChatBI Data Agent 以大模型 + Agent 编排为核心，打通【自然语言 → SQL → 数据 → 可视化 → 分析解读】完整链路，业务人员直接对话即可完成数据分析。
本项目不是单纯NL2SQL工具，是具备多轮对话、歧义确认、自动下钻、归因分析能力的数据智能Agent。

## 1.3 项目目标
### 核心目标
1. 支持用户使用自然语言自助查询、统计、对比、下钻分析数据
2. 构建标准化Agent工作流：语义解析 → 元数据匹配 → SQL生成 → 校验改写 → 执行 → 可视化 → 结论汇总
3. 统一指标口径，内置指标字典，降低指标歧义问题
4. 所有查询可溯源，每一次分析都附带原始SQL、执行日志
5. 支持多轮对话上下文理解，支持追问、二次拆解分析

### 非目标（项目边界）
1. 不实现完整数仓ETL、数据建模、离线调度平台
2. V1版本不引入复杂机器学习预测算法，仅做统计分析、异常归因解读
3. 不替代专业DBA、数据开发的复杂SQL开发工作

## 1.4 用户角色
1. **业务运营/产品人员**：高频简单取数、趋势查看、环比同比、生成周报
2. **业务分析师**：多轮下钻、异常排查、分层拆解、制作分析报告
3. **数据开发**：校验Agent生成SQL、维护元数据、维护指标字典、排查错误
4. **系统管理员**：数据源接入、权限配置、审计日志查看、能力开关管理

## 1.5 业务价值
1. 自助取数，减少数据开发重复取数需求，提升分析响应速度
2. 指标口径统一，沉淀业务指标知识库，减少“同指标不同结果”问题
3. 分析链路全链路可追溯，SQL、数据、结论一一对应
4. 分析结果支持图表、表格、Markdown报告导出，方便内部分享

## 1.6 需求范围
✅ 在范围内：
自然语言意图识别、歧义主动确认、元数据&指标库管理、NL2SQL生成、SQL安全&语法校验、SQL自动改写重试、SQL执行、自动图表渲染、数据解读、多轮对话记忆、权限隔离、审计日志、结果导出

❌ 不在范围内：
实时流计算、数据清洗、复杂预测建模、自助数据建模、大规模任务调度

## 1.7 验收标准
1. 简单查询（排行、汇总、趋势）NL2SQL准确率 ≥85%
2. 支持多轮指代追问：“去年同期对比”“按地区拆分”“只看TOP10”
3. 所有生成SQL支持查看、手动编辑、重新执行
4. 自动识别数据形态，输出合适图表：折线、柱状、饼图、表格、指标卡片
5. 数据权限隔离，用户无法访问无权限数据表
6. 全部查询行为落审计日志，可追溯操作人、时间、问句、SQL

## 1.8 风险概述
1. 大模型幻觉：表名、字段名写错，SQL生成错误；方案：元数据注入+校验+自动改写重试
2. 口径歧义：同一指标多种理解；方案：指标字典优先匹配，歧义主动反问确认
3. 慢SQL风险：大模型写出全表扫描SQL；方案：超时控制、行数限制、SQL预检

## 2.2 顶层能力清单（和GPT/Qwen/DeepSeek/豆包对齐）
1. **业务语义理解 & 歧义确认能力**
    - 识别用户意图：取数、趋势对比、占比分析、异常排查、生成报告
    - 自动识别指标、维度、时间范围、过滤条件、排序要求
    - 存在口径歧义时主动反问确认，不擅自猜测口径
2. **元数据与指标知识库能力**
    - 数据表、字段注释、表关联关系管理
    - 指标字典：指标名称、业务释义、标准SQL口径、同义词、负责人
    - 同义词映射：GMV、成交金额、交易额自动映射同一个指标
3. **NL2SQL完整Agent工作流（复用SQL Agent作业）**
    - 数据库解析 → 表选择 → SQL生成 → SQL语法校验 → SQL改写修复 → SQL执行
    - 安全拦截：禁止DELETE、DROP、ALTER、TRUNCATE等高危语句
4. **智能可视化能力**
    - 根据数据集特征自动选择图表类型
      - 时间序列数据 → 折线图
      - 分类对比数据 → 柱状图
      - 构成占比数据 → 饼图/环形图
      - 明细数据 → 数据表格
      - 单一汇总值 → 指标卡片
    - 支持用户手动指定图表类型：换成饼图、堆叠柱状图
5. **数据解读与结论生成能力**
    - 不只返回图表数据，自动输出业务解读结论：涨跌幅度、结构特征、关键变化点
    - 支持简单归因：指标下滑/上涨来自哪个维度
6. **多轮对话上下文记忆能力**
    - 记住上一轮的数据源、筛选条件、时间范围
    - 支持指代式追问，不需要重复输入全部条件
7. **异常探查下钻能力**
    - 用户提问“为什么销售额下跌”，Agent逐层下钻：整体 → 渠道 → 地区 → 产品定位原因
8. **报表与导出能力**
    - 自动生成Markdown分析周报、复盘报告
    - 支持明细CSV导出、图表图片导出
9. **人工干预修正能力**
    - 支持用户直接修改SQL，手动执行
    - 支持标注错误结果，反馈优化指标库
10. **安全审计与权限能力**
    - 表级权限控制，用户只能访问授权表
    - 敏感字段脱敏
    - 全链路审计日志留存

## 2.3 核心交互流程
```mermaid
flowchart LR
A[用户输入自然语言] --> B[意图识别 & 语义解析]
B --> C{是否存在歧义?}
C -->|是| D[Agent反问用户确认口径/条件]
D --> A
C -->|否| E[匹配指标库+元数据，选择数据表]
E --> F[生成初始SQL]
F --> G[SQL安全校验 + 语法校验]
G --> H{校验是否通过}
H -->|不通过| I[Agent自动改写SQL，重试]
I --> G
H -->|通过| J[下发引擎执行SQL]
J --> K{执行报错}
K -->|是| I
K -->|否| L[拿到结果集]
L --> M[自动选择图表渲染]
M --> N[大模型解读数据，输出结论]
N --> O[返回：图表+表格+结论+原始SQL]
O --> P[等待用户多轮追问]
