# ChatBI Agent 功能设计文档
> 文档版本：V1.0
> 文档状态：MVP定稿
> 适用对象：产品、后端、前端、测试
> 项目定位：面向公司内部业务人员的对话式BI Agent
> 数据源：MySQL
> 核心能力：自然语言转SQL、自动图表、自动分析报告、RAG增强、权限隔离、SQL安全校验、会话收藏、审计日志、预留MCP Client扩展

## 1. 概述
### 1.1 项目目标
搭建独立Web版ChatBI Agent，让无SQL基础的内部业务人员通过自然语言自助查询MySQL业务数据；自动输出表格、可视化图表、富文本分析报告。
配套能力：独立RBAC权限（行权限+列权限）、元数据定时同步、RAG检索增强、SQL安全拦截、SQL自动纠错重试、会话持久化、报表收藏、查询缓存、全链路审计日志；预留MCP Client接口，为后续工具扩展预留能力。

### 1.2 用户角色
1. **普通业务用户**
    - 对话提问、查看结果、手动修改SQL、管理会话、收藏报表
    - 只能在管理员分配的模型列表内选择大模型
2. **管理员用户**
    - 用户/角色管理、行列权限配置
    - 元数据同步管理、RAG参数配置
    - SQL安全规则、缓存管理、审计日志查询
    - 大模型接入、模型与角色权限绑定

### 1.3 MVP 范围边界（P0）
✅ 自然语言转SQL、自动生成图表、自动生成富文本分析报告
✅ 独立RBAC权限体系，行权限+列权限双层防护
✅ MySQL元数据定时增量同步，向量库RAG检索（仅数据字典）
✅ SQL执行前安全校验，拦截高危语句；用户自定义SQL同样走全套校验
✅ 多轮对话、会话持久化、会话命名
✅ 报表收藏，收藏打开时实时查询（优先走缓存）
✅ 查询缓存，缓存Key绑定用户权限上下文
✅ 全链路审计日志记录
✅ SQL执行失败自动重试，最多重试5次
✅ 接入国内大模型，按角色分配可用模型
✅ MCP Client接口预留，一期不实现鉴权
✅ 独立Web前端，聊天框为主，返回表格+图表+富文本报告

❌ 一期不实现：SaaS多租户、外网部署、数据脱敏、报告导出PDF/Word、会话分组、模型自动降级切换

### 1.4 非功能指标
- 预估同时在线用户：100人
- 大模型调用超时：60s
- 单查询最大返回行数：默认2000行（后台可配置）
- SQL最大自动重试次数：5次
- 缓存默认有效期：30分钟（后台可配置）
- RAG默认参数：混合检索（向量+关键词），TopN=8，相似度阈值0.65（后台可配置）

## 2. 整体业务主流程
> 链路方案B：先选表字段并校验合法性，再生成SQL
1. 用户输入自然语言问题
2. 身份鉴权，加载当前用户角色、用户属性（如dept_id）、权限白名单
3. RAG检索元数据（检索阶段自动过滤当前用户无权限的表、字段）
4. LLM第一步：理解需求，输出候选表、字段、维度、指标
5. 合法性校验：校验表、字段在元数据中真实存在，不存在直接拦截（规避幻觉）
6. LLM第二步：基于合法表字段生成SQL语句
7. SQL安全规则校验（高危SQL拦截）
8. 校验通过后，自动拼接行权限过滤条件
9. 提交MySQL执行

分支流程：
- ✅ 执行成功：返回结果集 → LLM自动判断图表类型生成图表配置 → LLM生成富文本分析报告 → 前端流式返回表格+图表+报告；写入缓存、写入审计日志
- ❌ 执行失败：记录数据库报错原文，最多自动重试5次；每次将原始问题、上一轮SQL、报错信息交给大模型修正；重试耗尽返回友好失败提示
- ⚠️ 问题歧义：模型识别缺少时间范围、维度、统计口径等信息，主动反问用户澄清，不强行生成SQL

## 3. 模块详细功能设计
### 3.1 用户与权限管理模块（独立RBAC）
#### 3.1.1 用户管理
- 功能：新增、编辑、启用/禁用用户
- 用户核心属性：用户ID、账号、用户名、用户属性（dept_id等，用于行权限变量注入）、所属角色列表、状态
- 规则：一个用户可绑定多个角色，权限取并集

#### 3.1.2 角色管理
- 功能：新建、编辑、删除角色
- 角色绑定配置项：
  1. 该角色允许使用的大模型列表
  2. 表-列权限：角色可以访问哪些表、哪些字段
  3. 表-行权限：为数据表配置过滤表达式，支持变量 `${current_shturl.c}`，示例：`dept_id = ${current_user.dept_id}`

#### 3.1.3 列权限双层防护策略
1. 第一层（源头拦截）：RAG检索阶段直接过滤掉无权限字段，向量结果不返回
2. 第二层（兜底校验）：SQL生成完成后，解析SQL字段列表，校验是否包含无权限字段，命中直接拦截
> 用户手动修改SQL提交，同样完整执行列权限 + 行权限校验

#### 3.1.4 行权限策略
SQL安全校验通过后，自动把行权限条件拼接到SQL的WHERE子句，实现行级数据隔离。

### 3.2 元数据管理 & RAG检索模块
#### 3.2.1 MySQL元数据同步
- 同步内容：数据库表名、表注释、字段名、字段注释、字段类型、所属表
- 同步方式：定时增量同步（Cron表达式后台配置）；支持管理员手动触发全量重建向量库
- 异常处理：同步失败记录日志，管理员后台查看同步记录；同步失败不影响存量向量数据使用

#### 3.2.2 RAG检索能力
- 向量库存储内容：仅数据字典（表、字段、注释），不存储业务文档、指标文档
- 检索模式：向量相似度检索 + 关键词混合检索
- 参数：TopN返回数量、相似度阈值后台可配置
- 内容处理：检索到的片段全部原文送入大模型，不做摘要压缩
- 权限联动：检索时根据当前用户角色过滤无权限表、字段

### 3.3 对话会话管理模块
#### 3.3.1 会话管理
- 用户操作：新建会话、自定义会话名称、删除本人会话
- 存储策略：会话持久保存；管理员后台支持批量清理会话
- 多轮上下文携带规则：携带历史提问、历史SQL、结果摘要；**禁止携带原始明细数据**，防止上下文超长与数据泄露

#### 3.3.2 消息管理
- 一条会话包含多条消息：用户消息、Agent回复消息
- Agent消息结构：问题理解、选中表字段、生成SQL、SQL校验结果、表格数据、图表配置、分析报告、错误信息
- 传输方式：SSE流式输出，逐步返回思考、SQL、图表、报告内容

### 3.4 NL2SQL & SQL安全校验模块
#### 3.4.1 NL2SQL生成流程
1. 需求理解 + 选表选字段：大模型结合用户问题+RAG元数据输出候选表、字段
2. 合法性校验：校验表、字段在元数据真实存在，不存在直接拦截
3. SQL生成：大模型基于确认的表字段生成可执行SQL

#### 3.4.2 SQL安全校验（基于成熟SQL解析组件）
命中任意一条规则直接拒绝执行：
- DDL语句：CREATE / ALTER / DROP / TRUNCATE
- DML写语句：INSERT / UPDATE / DELETE
- 无LIMIT、存在全表扫描风险语句
- 预估结果集超过配置上限语句

#### 3.4.3 SQL自动重试机制
- 触发条件：MySQL执行异常（语法错误、字段不存在等）
- 最大重试次数：5次
- 重试逻辑：原始问题 + 上一轮SQL + 数据库报错原文一起传入大模型重新生成SQL
- 终止条件：达到5次上限，停止重试，返回失败提示

#### 3.4.4 用户自定义SQL
聊天卡片支持编辑AI生成的SQL，提交执行；修改后的SQL必须完整走安全校验、行列权限校验流程。

### 3.5 图表与自动分析报告模块
#### 3.5.1 图表生成
- 大模型根据数据特征自动推荐图表类型（柱状、折线、饼图等）
- 前端支持切换图表类型；图表库由前端自行调研选型
- 图表配置信息存入收藏记录，不持久化明细数据

#### 3.5.2 自动分析报告
- 展示形式：富文本，内嵌对话内表格、图表引用
- 报告内容：指标解读、趋势说明、对比结论、业务洞察
- 一期仅在线查看，不支持导出Word/PDF

### 3.6 报表收藏模块
- 用户可以收藏任意一次成功的分析结果
- 收藏存储字段：原始提问、生成SQL、图表配置、分析报告文本
- 打开收藏逻辑：**不读取历史明细，重新发起查询，自动走权限校验与缓存逻辑**，保证数据实时性
- 支持对收藏报表二次编辑SQL，重新查询

### 3.7 缓存管理模块
#### 3.7.1 缓存规则
- Cache Key：用户ID + 用户权限标识 + 标准化问题文本 + SQL文本
> 同一个问题，不同用户权限不一样，缓存隔离，不可共用
- 默认过期时间：30分钟，后台可配置
- 黑名单：后台配置禁止缓存的数据表，命中黑名单查询不写入缓存

#### 3.7.2 缓存后台管理
管理员后台：缓存列表查看、单条删除缓存、一键清空全部缓存

### 3.8 大模型接入模块
- 支持接入多款国内大模型；后台录入模型地址、密钥、模型名称
- 权限控制：模型绑定角色；普通用户只能在角色分配的模型列表内选择
- 调用规则：单模型调用超时60s；一期超时直接返回失败，不自动切换备选模型
- 模型分工：同一个模型承担需求理解、选表字段、生成SQL、生成图表配置、撰写分析报告

### 3.9 MCP客户端预留模块
- 定位：系统作为 MCP Client，预留标准调用接口
- MVP阶段：仅封装调用框架与参数结构，**不实现鉴权、不接入具体MCP工具**
- 扩展方向：后续对接外部数据源、通知服务、业务工具等MCP Server

### 3.10 审计日志模块
- 记录字段：用户ID、会话ID、提问内容、RAG检索片段、选中表字段、生成SQL、SQL校验结果、执行状态、返回行数、执行耗时、报错信息、选中模型、时间戳
- 存储策略：永久保存，日志不脱敏
- 后台功能：审计日志列表、多条件检索（用户、时间、会话、执行结果）

## 4. 前端页面功能清单
1. 登录页：账号登录，加载用户身份与用户属性
2. 对话首页（主页面）
    - 左侧：会话列表、新建会话、删除会话
    - 右侧：聊天输入框、模型下拉选择框（角色权限范围内）
    - 消息卡片：用户提问；Agent回复（思考过程、SQL代码块、表格、图表、富文本报告、收藏按钮、编辑SQL按钮）
3. 个人收藏页：收藏报表列表，点击打开，支持编辑SQL重查
4. 管理员后台（独立路由）
    - 用户管理、角色管理
    - 行列权限配置页面（按表配置）
    - 元数据同步配置、同步记录查看
    - RAG参数配置页（TopN、相似度阈值）
    - SQL安全规则配置、查询行数上限配置
    - 缓存管理页面
    - 大模型接入配置、模型-角色绑定配置
    - 审计日志查询页面

## 5. 提示文案规则
1. 元数据同步失败：后台日志记录，管理员后台可见
2. 高危SQL拦截：当前SQL存在风险，禁止执行
3. 权限拦截：您没有该表/字段访问权限
4. 模型超时：大模型请求超时，请重试
5. SQL重试耗尽失败：多次修正SQL仍执行失败，请检查问题描述或手动调整SQL
6. 问题歧义：Agent主动反问，示例：请问需要统计哪个时间段的数据？
