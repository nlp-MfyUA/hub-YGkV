# 差异对比

**前提：需求输入一样**

|                      | 无script脚本                                                 | 有script脚本                        |
| -------------------- | ------------------------------------------------------------ | ----------------------------------- |
| **稳定性**           | 弱于有脚本，比较受限于Agent以及所用LLM能力                   | 效果较为稳定                        |
| **生成HTML报告速度** | 要二十多分钟                                                 | 不到 1 秒                           |
| **生成的HTML成本**   | 高（因为脚本可能不复用，导致可能会多次调用LLM，进行脚本生成和修改，再进行效果确认） | 低（只有第一次生成脚本的token费用） |
| **生成的HTML一致性** | 一般（脚本可能不复用，导致可能多次调用LLM，LLM给出的结果不一定一致） | 高                                  |
