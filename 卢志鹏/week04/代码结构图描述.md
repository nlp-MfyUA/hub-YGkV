## 项目代码结构图

这是一个**意图识别（Intent Classification）Web 应用**，基于 FastAPI，提供 BERT 微调模型和 LLM + Few-shot 两种分类方式。

### 目录结构



```
intent-classify/
├── main.py                  # FastAPI 主入口，暴露两个分类路由
├── config.py                # 全局配置（LLM、BERT、数据集路径）
├── data_schema.py           # Pydantic 请求/响应数据模型
├── logger.py                # 全局日志配置（文件 + 控制台）
├── test_routes.py           # 路由接口测试脚本
├── requirements.txt         # 依赖清单
├── dataset/
│   └── dataset.csv          # 训练/采样数据集（tsv 格式：文本\t标签）
├── logs/
│   ├── app.log              # 运行日志
│   └── 路由测试结果.txt      # 路由测试输出
├── model/                   # 预测模型封装
│   ├── __init__.py
│   ├── bert_model.py        # BERT 微调模型加载 + 预测
│   └── gpt_model.py        # LLM + Few-shot 预测
└── tuning_model/           # BERT 微调产物（checkpoint）
    ├── warmup_steps_10/checkpoint-75/   # 调优模型 checkpoint
    └── 基线/checkpoint-100/             # 基线对照模型
```

### 核心流程说明

**1. 配置层** [config.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/config.py)

- `LLM_*`：阿里云 DashScope 兼容 OpenAI 接口（deepseek-v4-flash）
- `BERT_MODEL_PATH`：本地 `bert-base-chinese` 基座
- `BERT_CKPT_PATH`：调优后的 checkpoint-75
- `DATASET_PATH`：`./dataset/dataset.csv`

**2. 数据契约层** [data_schema.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/data_schema.py)

- `TextClassifyRequest`：`request_id`（可选）+ `request_text`（支持 `str` 或 `List[str]`）
- `TextClassifyResponse`：`classify_result` / `classify_time` / `error_msg`

**3. 模型层** [model/](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/model/)

- [bert_model.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/model/bert_model.py)：模块导入时即加载 — 用数据集前 500 条构建 `LabelEncoder`，加载 tokenizer 与微调 checkpoint，`predict()` 对文本 tokenize → BERT 前向推理 → `argmax` → 反解码为标签名
- [gpt_model.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/model/gpt_model.py)：模块导入时即按标签分组各采 2 条作为 Few-shot 样本，构造提示词模板，`predict()` 逐条调用 LLM（`temperature=0`）返回类别名

**4. 路由层** [main.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/main.py)

- 两条 POST 路由共享同一套流程：`_normalize_texts`（兼容单字符串/列表）→ 调用对应 `predict` → 计时 + 异常捕获 → 返回统一响应
- `_build_response` / `_normalize_texts` 为内部辅助函数

**5. 测试与产物**

- [test_routes.py](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/test_routes.py)：对两个路由发起请求测试
- [tuning_model/](vscode-webview://0kts31vdobqok6hlekom14ei9mbs8s3p6h5athsc9ivseh7vjvv3/tuning_model/)：BERT 微调训练产物，含 `warmup_steps_10/checkpoint-75`（调优）与 `基线/checkpoint-100`（对照）
